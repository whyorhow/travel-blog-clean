# Template Capability Matrix

**Purpose:** Prevent "hybrid drift" — uncontrolled blending between Dense and Light template philosophies.

**Rule:** Pages must commit to ONE template class. Features are either required, optional, or forbidden based on that choice.

---

## Dense Editorial Template

**Philosophy:** Modular • Exploratory • Branching • Navigational  
**Metaphor:** *City as network*

| Feature | Status | Behavior |
|---------|--------|----------|
| **Hero** | required | Cinematic preferred (diary), fallback acceptable |
| **Map** | required | Spatial context is non-negotiable for dense hubs |
| **Subsections** | required | 3-4 sections minimum, navigation system active |
| **Unified Narrative Container** | forbidden | Modular separation required |
| **ReflectiveClose** | optional | Can end with gallery or continue exploring |
| **Gallery** | optional | Secondary to subsection navigation |
| **NarrativeSplits** | modular | Standalone blocks between sections |
| **RhythmInserts** | encouraged | Atmospheric pauses between subsections |
| **BridgeQuotes** | optional | Transitional moments as needed |

**Example:** São Paulo

---

## Light Destination Template

**Philosophy:** Immersive • Linear • Reflective • Continuous  
**Metaphor:** *Place as memory*

| Feature | Status | Behavior |
|---------|--------|----------|
| **Hero** | required | Any tier acceptable, consistent 60vh+ presence |
| **Map** | optional | Only if spatial context adds value |
| **Subsections** | forbidden | Unless exceptional justification exists |
| **Unified Narrative Container** | required | Continuous torn-paper flow |
| **ReflectiveClose** | required | Narrative conclusion before gallery |
| **Gallery** | encouraged | "Additional fragments beyond the written account" |
| **NarrativeSplits** | embedded | Inside unified container only |
| **RhythmInserts** | required | 1-2 atmospheric pauses minimum |
| **BridgeQuotes** | required | At least one transitional moment |

**Example:** Rio de Janeiro

---

## Forbidden Patterns (Anti-Drift Rules)

These combinations indicate template confusion:

1. **Light page with subsections** → Violates linear flow
2. **Dense page with unified container** → Destroys modularity
3. **Light page without ReflectiveClose** → No narrative closure
4. **Dense page without map** → Missing spatial anchor
5. **Gallery inside unified container** → Mixes authored/archive layers

---

## State Change Boundaries

| Transition | Dense Template | Light Template |
|------------|---------------|----------------|
| **Hero → Content** | Immediate modular split | Seamless unified entry |
| **Content → Gallery** | Optional, post-navigation | Required, post-ReflectiveClose |
| **Gallery → End** | Often continues to related | Clean termination |

---

## Implementation Rule

When creating a new destination page:

1. **Classify first:** Is this a hub ('dense') or memory ('light')?
2. **Select template:** Use matrix to determine available features
3. **Enforce constraints:** Forbidden features are non-negotiable
4. **Document exceptions:** Any deviation requires explicit justification
